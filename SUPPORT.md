# Support

## Documentation

Start with the [README](README.md): what the app does, how to run it, the worked example and the API. Deeper material is in [docs/](docs/): [architecture](docs/architecture.md), [methodology](docs/methodology.md), [reproducibility](docs/reproducibility.md), [use cases](docs/use-cases.md) and [limitations](docs/limitations.md). The ML model is described in [MODEL_CARD.md](MODEL_CARD.md) and the bundled data in [DATA_CARD.md](DATA_CARD.md).

## Questions

Ask usage questions in [GitHub Issues](https://github.com/pavangemmanjunath-cell/GridRescue_AI/issues). Search existing issues first. Discussions are not enabled yet.

## Bug Reports

Use the **Bug report** issue form. Include the version, your operating system, the steps to reproduce, and what you expected.

## Feature Requests

Use the **Feature request** issue form. Describe the problem first, then the capability you propose.

## Research Questions

Use the **Research question** issue form for questions about the method, the assumptions, the ML model or reproducing a result.

## Security Problems

Do not post vulnerabilities publicly. Follow [SECURITY.md](SECURITY.md).

Support is given on a best-effort basis by the authors.
